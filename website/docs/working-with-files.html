Working with Files

Part files

Parts are saved as .rcad files, assemblies as .rasm and drawings as .rdrw files (see the Drawings chapter).

CommandShortcutNotes
File ▸ New PartCtrl+NOpens in a new tab
File ▸ Open…Ctrl+OOpens parts, drawings, STEP and STL files
File ▸ Open Sample PartThe built-in sample, in a new tab
File ▸ SaveCtrl+SUses the normal Windows save dialog the first time
File ▸ Save As…Ctrl+Shift+SSaves a copy under a new name

Tabs and closing

Several parts and drawings can be open at once, each in its own tab. New, Open and Sample all open a new tab. Closing a tab with unsaved changes asks whether to save it, and closing RazorCAD asks to save every unsaved part.

Auto-save and recovery

Auto-save starts once a part has been saved for the first time. While the part has unsaved changes it is written next to the part file, at most every 20 seconds, as Name.autosave.rcad. The title bar shows the time of the last auto-save. Saving the part removes the auto-save file.

If RazorCAD closes with unsaved changes, opening the part again offers to recover the auto-saved version. It is also marked in the recent list.

Warning: A part that was never saved is not auto-saved. RazorCAD warns before closing it. Save new parts early.

The recent-files list is kept in %APPDATA%\RazorCAD\recent.json.

Importing STEP and STL

There are two ways to bring in a STEP or STL file:

  • File ▸ Open… opens it as a part of its own in a new tab, named after the file, without asking. A STEP file that holds an assembly asks first:
    • Open as an Assembly makes a new assembly with the file's structure: a sub-assembly for each of its sub-assemblies, a part for each part, and a component, fixed, where the file places each one. Each part keeps its own piece of the STEP file and is built on its own, and a part used several times is built once.
    • The first build of each part is kept on disk (in %LOCALAPPDATA%\RazorCAD\modelcache, up to 1 GB, shared with parts). The next time the assembly opens, unchanged parts are shown straight from there instead of being rebuilt, so a big assembly reopens in seconds.
    • Open as One Part brings every solid into one part, as before.
  • File ▸ Import STEP / STL… (Ctrl+I, also on the Features and Evaluate tabs) offers three choices: a new part, insert in place into the current part, or insert and locate with mates. Locating with mates adds a separate "Locate …" Move Body feature under the import.

How imports behave:

  • The file's contents are stored inside the part file, so the part does not depend on the original file.
  • A STEP file's appearances come with it: the colour of each solid and of single faces, and transparency. Your own Appearance and Make Transparent / Make Opaque settings on a body win over them.
  • STEP imports as an exact solid. Every solid becomes its own body; a solid made of several separate shells is split into one body per shell; loose surfaces become surface bodies.
  • The bodies of a multi-body STEP file are grouped in their own folder under Solid Bodies.
  • Tick Merge touching bodies into one body in the import feature to fuse them instead.
  • An STL is converted to a solid made of its triangles. Coplanar triangles are merged. Meshes up to 200,000 triangles are accepted.
  • Imported bodies can be cut, extended, patterned and (for STEP) filleted like any other body.

Sub-assemblies

An assembly can hold other assemblies as components. Insert Components ▸ Browse for a Part or Assembly… takes a .rasm file, and STEP assemblies keep their sub-assemblies when they open as an assembly.

  • A sub-assembly is kept whole, with its own parts, placements and configurations, and moves as one. Clicking any of its parts picks it.
  • Mates can use the faces, edges and vertices of the parts inside it.
  • In the tree, ▶ opens a sub-assembly to show its components. Double-click one, or right-click the sub-assembly ▸ Open Sub-assembly, to change it in its own tab; the changes come back to the assembly.
  • The Bill of Materials is indented: a sub-assembly's parts are listed under it (1.1, 1.2…), with the quantities in one of it.

Every assembly has the standard Front, Top and Right Planes and the Origin at the top of its tree. They show in the view as a part's do (the eye in the tree, View ▸ Show Planes), and mates can use them; they stay where they are.

Selecting in an assembly works as in a part and follows the selection filter: with no filter a click picks the vertex, edge, face or plane under the cursor; with the Bodies filter it picks whole components. Ctrl+click adds or takes away. Right-click a face, edge or vertex for Mate… and the component's commands; whatever is selected goes into the mate. Dragging a component moves it, whatever is selected.

Saving parts as separate files. When an assembly holds parts or sub-assemblies that are only inside it (as a STEP assembly does when it opens), Save asks how to save them:

  • Save Parts as Separate Files saves each part as a .rcad file and each sub-assembly as a .rasm file in the assembly's folder, named after them. The assembly (and each sub-assembly) then uses those files, so each part can be opened and changed on its own and the change shows in the assembly. A part used in several places is one file. If files of those names are already there, you are asked before they are replaced.
  • Save as One File keeps everything inside the assembly file. You are not asked again, except on Save As.

Exporting

Export Face as DXF

Click a flat face, then right-click ▸ Export Face as DXF… (or File ▸ Export ▸ Face as DXF…). The face's outline (layer OUTLINE) and holes (layer HOLES) are written as a 2D drawing in millimetres, seen from outside the part. Use it for laser or waterjet cutting, or to take a profile into a 2D CAD program.

Lines, arcs and circles are exact; other curves become fine polylines. The file is DXF R12, which practically every program can read.
